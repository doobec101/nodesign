# motion — «One shape» (ds-promo)

Одна фигура, без склеек: кнопка → промо-кнопка → иконка → лоадер → поле → промо → curves-1…7 → снова кнопка. 38,4 с, 150 BPM, такты 9–32 трека Mixkit «Can't Get You Off My Mind» (Michael Ramir C.). 1600×1200 — как превью чата на сайте (`media/moex-chat`, 4:3).

| Файл | Что это |
|---|---|
| `ds-promo.html` | всё в одном файле: разметка, `seek(t)`, шрифт Inter (400/500/600, OFL), данные бита и эквалайзера |
| `renders/ds-promo-dark.mp4`, `renders/ds-promo-light.mp4` | 60 fps, motion blur (4 подкадра → `tmix`), звук |
| `renders/ds-promo-audio.m4a` | микс: музыка + UI-звуки; его же играет превью |
| `data/beats.json` | сетка бита, структура трека, окно лупа, эквалайзер 9 полос × 120 Гц |
| `data/cues.json` | звуковые события, которые объявляет страница |
| `tools/` | `beatgrid.py` → `embed.py` → `sounds.py` → `render.mjs` |

## Как устроено

- **Время — единственный вход.** `seek(t)` считает каждый стиль из `t`: ни CSS-переходов, ни таймеров, ни состояния между кадрами.
- **Пружины в замкнутой форме.** Значение = `v0 + Σ Δk · (S(t − tk) + S(t − tk + LOOP))`: по одной переходной характеристике на каждую смену цели плюс копия из прошлого круга. Поэтому последний кадр переходит в первый с той же позицией и скоростью (курсор и камера тоже). Демпфирование ≥ 0,8 — перелёт не больше 1,5 %.
- **Камера** — пружины центра и `log(zoom)`; каждое состояние заполняет кадр. `will-change` нигде нет, текст растеризуется в итоговом масштабе.
- **Смена контента** — у уходящего и приходящего слоя свои тайминги (уход быстрее, приход позже), размытие задаётся в экранных пикселях.
- **Кривые** встают по полосам, как эквалайзер: каждая точка тенора поднимается на свою шестнадцатую, а поверх — уровень полосы из самого трека. В curves-7 все шесть кривых играют музыку.
- **Промо-кривые — струны.** Курсор проводит по ним с зажатой кнопкой; каждая звучит нотой Karplus-Strong в тональности трека (ми минор: B4, G4, E4).

## Трек

`beatgrid.py` (только numpy): автокорреляция огибающей атак даёт 0,8 / 0,4 с; подгонка постоянной сетки — 0,40000 с = 150,000 BPM без дрейфа. Сильные доли — по хроме: меньше всего гармонических смен на 4-й доле, дроп бьёт ровно в 25,6 с. Структура: такты 1–8 — фильтрованное интро, 9–16 — фильтр открывается и бас уходит (билд), 17 — дроп, дальше фразы по 8 тактов со стопами в конце 20, 24, 28 и филлом в 32.

Луп — такты 9–32 (12,80–51,20 с, 96 долей). Маленький UI живёт в билде, виджет раскрывается ровно на дроп, филл 32-го такта уходит в начало. Шов звука — 12 мс кроссфейда в то, что в треке звучит перед 9-м тактом.

## Звуки

`sounds.py` синтезирует их сам (клики, тики, моргания, вжухи, аккорды, щипки) и ставит каждый так, чтобы **его измеренный пик** (огибающая 1 мс, argmax) пришёлся на событие. Вжухи морфа пикуют в момент максимальной скорости пружины (≈ 0,1 с после старта). Всё, что звенит за концом лупа, заворачивается в его начало.

## Пересобрать

Сам mp3 в репозитории не лежит (лицензия Mixkit не разрешает раздавать трек отдельным файлом). Скачай его с Mixkit в `motion/audio/song.mp3`. Нужны `pip install numpy imageio-ffmpeg` и Playwright (глобальный тоже подойдёт).

```bash
python3 motion/tools/beatgrid.py                         # data/beats.json
python3 motion/tools/embed.py [путь/к/@fontsource/inter/files]   # данные (и шрифт) внутрь html
node motion/tools/render.mjs cues > motion/data/cues.json
python3 motion/tools/sounds.py                           # renders/ds-promo-audio.m4a
node motion/tools/render.mjs beats dark                  # кадр на каждую долю → out/beats-dark-*.jpg
node motion/tools/render.mjs video dark 3                # renders/ds-promo-dark.mp4 (3 воркера)
node motion/tools/render.mjs video light 3
```

Превью: открой `ds-promo.html` (пробел — play, `?theme=light`, `?t=12.8`).

## Отступления от макета

- Цвета — только токены ds-promo (Component collection, режимы Dark/Light). Канвас — Background/Main (#000 / #FFF).
- У трёх токенов графика (`bg/widget/analytics-data`, `text/charts/default/secondary`, `line/interface/secondary-backing`) в библиотеке есть только тёмное значение. В светлой теме это Background/Level1, Text/Secondary и Stroke/Divider.
- Текст тоста в светлой теме — белый Button/Text/Primary: Text/Primary на зелёном давал контраст 2,7:1.
- Точка в промо (#915FFF вне токенов) → Button/Fill/Primary/Hover (#9B6AEA). Белые 16 % под мини-кривыми → цвет самой линии на 16 %.
- Кривые одного цвета с точками легенды: KEYRTE — зелёный целиком, CSARUB — красный.
- Три добавленные кривые — chart/multi yellow, teal, blue: RUB-FWC-RUSFAR, RUB-FWC-MOSPRIME, RUB-DSC-OFZ. Шестой чип не влезает в строку, легенда переносится, график ужимается пружиной.
- Меню Period / Currency / Curve type собраны из дропдауна кривых со своими пунктами.
- Опечатки: «Trail ends with saved dats» → «Trial ends with saved data», «Thats it!» → «That’s it!».
- Пустое промо на чёрном канвасе обведено Stroke/Divider, иначе карточка сливается с фоном.
